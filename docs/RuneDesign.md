# 룬 시스템 설계 문서

## 설계 원칙 (Dark Hunting Ground 슬레이트 시스템 참조)

1. **원소 룬은 스킬 당 1개 한정** — 원소 정체성 충돌 방지
2. **증폭 룬은 중복 장착 가능** — 같은 룬 여러 개 = 더 강한 효과
3. **변환 룬은 추상적으로 정의** — 스킬 타입과 무관하게 적용, 각 스킬이 해석 방식 결정
4. **트레이드오프 룬 존재** — Rare 이상 일부 룬은 얻는 게 있으면 잃는 게 있음
5. **VFX는 기능의 시각적 반영** — 코스메틱 전용 레이어 없음, 기능이 바뀌면 VFX도 바뀜

## 카테고리 구조

```
원소 룬   (16개) ── 속성 부여 + 상태이상 메카닉, 스킬 당 1개
변환 룬   (10개) ── 발동/형태 변환, 중복 불가
증폭 룬   (10개) ── 수치 강화, 중복 가능
심연 룬   (10개) ── Legendary, 게임 규칙 변환
────────────────
총         46개
```

## 원소 룬 (16개)

> 장착하면 스킬에 원소가 부여되고, 상태이상 메카닉이 활성화됨.
> 스킬 당 1개 한정. 등급이 높을수록 상태이상이 심화됨.

| 원소 | 중첩 누적 효과 | 폭발/해제 조건 |
|---|---|---|

| 바람 (부유) | 짧은 공중 띄우기 + 넉백 증폭 | 부유 중 충돌 시 추가 피해 (Epic 이상) |
| 대지 (균열) | 방어력 -8% per 중첩, 최대 3중첩 | 3중첩 시 스턴 (Epic 이상 룬 장착 시) |

## VFX 레이어 구조 (요약)

```
[발동 VFX]  ← 차징 구체, 채널 스트림, 설치 기둥, 증강 오라   (TRF 발동 룬)
[속성 VFX]  ← 불꽃, 얼음 결정, 소용돌이, 돌 파편             (원소 룬)
[형태 VFX]  ← 잔상, 나선, 번개 아크, 궤적, 미니 발사체        (TRF 형태 룬)
[강도 VFX]  ← 위 레이어들의 밝기/크기/속도 배율               (증폭 룬)
[심연 VFX]  ← 고유 이펙트, 항상 최상위 레이어                 (심연 룬)
```

**조합 예시:**
- `화속(FIR_1) + 관통(TRF_PRC) + 강타(AMP_DMG1)` → 오렌지 불꽃 투사체, 긴 잔상, 밝은 충돌
- `결빙(WAT_3) + 차징(TRF_CHG) + 범위(AMP_RAD1)` → 파란 에너지 구체 충전 → 빙결 폭발
- `지진(ERT_3) + 연쇄(TRF_CHA) + 처형자(ABY_EXC)` → 스턴 + 번개 연쇄 + 처형 표적 UI

## 슬롯 수

현재 코드: 스킬 당 3슬롯 (`RUNES_PER_SKILL = 3`)

권장 조합 예:
- 원소 1 + 변환 1 + 증폭 1 (다양성)
- 원소 1 + 증폭 2 (화력 집중)
- 변환 2 + 증폭 1 (특수 동작 중심)
- 증폭 3 (수치 극대화)

필요시 4슬롯으로 확장 검토 (원소 1 + 변환 1 + 증폭 2).
