스킬 아이콘 PNG를 이 폴더에 넣으세요.

파일명 = 스킬 이름(SkillData.name)과 정확히 일치해야 자동 로드됩니다.
예) Fireball.png, FireBeam.png, Meteor.png, WaterPuddle.png, WaterWave.png,
    WaterVortex.png, TidalWave.png, WaterOrb.png, WaveSlash.png,
    WindCutter.png, GaleRush.png, Tornado.png, WindShot.png,
    StoneSpikes.png, RockThrow.png, Earthquake.png, EarthShard.png, EarthArmor.png

- 정사각형(예: 256x256 또는 1024x1024), 투명 배경 PNG 권장.
- 파일이 없으면 원소색 단색 타일 + 조작키 글자로 자동 폴백됩니다.
